About this QR code generator

A QR code is just text drawn as a pattern: a web address, a Wi-Fi login, an email address or a short message, encoded so a phone camera can read it in one scan. This generator draws that pattern entirely in your browser with qrcode-generator, a small open-source library served from this site — nothing you type is sent to a server, there is no account, and there is no watermark on the download.

Every code here is static: the content is baked into the pattern itself. That means it never expires, has no scan limit, and keeps working even if this site disappears — but it also means you cannot change what a printed code points to afterwards. If the link moves or the Wi-Fi password changes, print a fresh code.

How each type is encoded

  • Link / URL — the address itself, e.g. https://example.com/menu. Scanning opens it in the browser.
  • Text — plain text, shown on screen after scanning. Good for a short message, a Wi-Fi-free notice, or an address.
  • Wi-Fi — the standard WIFI:T:WPA;S:NetworkName;P:password;; format. Phones recognise it and offer to join without typing the password. Special characters in the name or password are escaped automatically.
  • Email — a mailto: link, with subject and message if you add them. Scanning opens the email app ready to send.
  • Phone call — a tel: link. Scanning offers to dial the number.
  • SMS — a SMSTO:number:message link. Scanning opens the messaging app with the text pre-filled.

Common ways people use QR codes

Wi-Fi for guests. A café, guesthouse or office prints one code at the counter or on each table; guests join without asking for — or mistyping — the password. Print it at least 3 cm across so older phones can read it from a normal distance.

Menus, posters and flyers. A code on a poster links to the full menu, the booking page or the event sign-up, so the print stays short and the details stay current online. Use the SVG download for print — it stays sharp at any size.

Business cards. A code linking to your website or a pre-addressed email lets someone reach you without typing a long address from a card.

Contactless payments and check-ins. Many small sellers put a code at the till linking to a payment page or a feedback form — one scan, no app to install.

How to use

  1. Pick what the code should contain — link, text, Wi-Fi, email, phone or SMS.
  2. Fill in the details. The code updates as you type.
  3. Choose a size and error-correction level (M suits most uses; Q or H for print that will get rough handling).
  4. Scan it with your own phone to check it opens the right thing.
  5. Download PNG for screens and documents, or SVG for print.

Limitations

  • Static codes only — no tracking, no scan counts, no editable "dynamic" codes, and no logo embedded in the code. (A logo over the middle needs high error correction and can break scanning; keep codes clean.)
  • About 2,900 characters maximum in one code; long URLs make dense codes that are harder to scan — shorten the link first if the pattern looks very dense.
  • Very light code colours or low contrast can fail to scan. Black on white is the most reliable; if you pick colours, test the scan before printing.
  • Wi-Fi codes share the password with anyone who can see them — only display them where guests are meant to see them.
  • Some older phones need a scanner app; the built-in camera works on current iPhones and Android phones.

Frequently asked questions

Is this QR code generator really free with no sign-up?

Yes. There is no account, no email address and no limit on how many codes you make. The generator runs entirely in your browser using a small open-source library served from this site.

Do the QR codes expire?

No. These are static QR codes: the link, text or Wi-Fi login is encoded directly into the pattern itself, so the code works forever. There is no subscription to lapse and no server that can switch the code off. The only exception is the content itself — if you change your Wi-Fi password or move the web page, print a new code.

Is my Wi-Fi password sent anywhere?

No. The code is generated on your own device — your Wi-Fi password, links and text are never uploaded to any server. Anyone who can see the printed code can read the password from it, though, so only display a Wi-Fi code where guests are meant to see it.

What is error correction, and which level should I pick?

Error correction is built-in redundancy: part of the code can be damaged or covered and it still scans. L tolerates about 7% damage, M about 15%, Q about 25% and H about 30%. M is the right default for screens and clean print; use Q or H if the code will be printed small, outdoors, or partly covered.

Should I download PNG or SVG?

SVG for print — it is a vector, so it stays sharp at any size, from a business card to a poster. PNG for screens, chats and documents where an image file is expected; pick 1024 px for the sharpest result.

Will my phone read a Wi-Fi QR code?

On current iPhones and Android phones, yes: point the built-in camera at the code and the phone offers to join the network without typing the password. Older phones may need a QR scanner app. The code uses the standard WIFI:T:…;S:…;P:…; format that phones understand.

What happens if I change my Wi-Fi password?

The old code stops working, because the old password is baked into it. Generate a fresh code with the new password and replace any printed copies.
