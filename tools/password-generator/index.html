About this password generator

Weak and reused passwords remain the most common way accounts get compromised. A strong password needs to be long and random — two things humans are bad at producing. This free password generator creates cryptographically random passwords of any length from 4 to 64 characters, mixing uppercase, lowercase, digits and symbols, with an option to exclude ambiguous characters (l, 1, I, 0, O) that are easy to misread.

Randomness quality is what separates a real password generator from a toy. This tool uses only your browser's WebCrypto API (crypto.getRandomValues) — the same source of randomness behind TLS encryption keys. If WebCrypto is unavailable, the generator shows an error and refuses to run rather than silently falling back to the weaker Math.random(). Every password is guaranteed to contain at least one character from each character set you enable, and an entropy readout (in bits) plus a plain-English strength label tells you exactly how strong the result is: 16 characters from all four sets gives roughly 103 bits of entropy — strong for almost every purpose.

Because generation happens entirely on your device, passwords are never transmitted, stored or logged. For real security, store each generated password in a reputable password manager and never reuse passwords across sites.

How to use

  1. Choose a length with the slider (16 is a strong default; 20+ for master passwords).
  2. Tick the character sets you want; optionally exclude ambiguous characters.
  3. Click Generate (or Regenerate for a new one).
  4. Check the entropy and strength readout, then Copy the password into your password manager.

Limitations

  • Some websites restrict password length or ban certain symbols — adjust the options to match the site's rules.
  • The generator cannot check whether a password has appeared in a data breach; avoid reusing passwords regardless.
  • Strength labels estimate resistance to brute force; they do not protect against phishing or malware on your device.
  • Requires a browser with WebCrypto support (all modern browsers); the tool refuses to generate without it.

Frequently asked questions

How random are the generated passwords?

Passwords are generated with your browser's WebCrypto API (crypto.getRandomValues), the same cryptographic randomness used for TLS keys. The generator refuses to run if WebCrypto is unavailable — it never falls back to weaker Math.random().

What password length should I choose?

16 characters from the full character set gives about 103 bits of entropy, which is strong for almost every purpose. Use 20+ for master passwords and anything protecting sensitive accounts. The slider goes up to 64.

What does "exclude ambiguous characters" do?

It removes characters that are easy to confuse when reading: lowercase l, digit 1, uppercase I, digit 0 and uppercase O. Useful when you must read or type a password manually.

Are my passwords sent anywhere?

No. Generation happens 100% in your browser. Passwords are never transmitted, stored or logged — they exist only on your device until you copy them.
