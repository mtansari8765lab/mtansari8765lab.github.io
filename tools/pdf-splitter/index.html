    About this PDF splitter

    A 40-page report where you only need chapter 2. A scanned contract where only the signed page matters. A bank statement where one month's pages go to the accountant. Splitting a PDF is the opposite job to merging one — and like the merger on this site, it runs on pdf-lib, a real PDF engine that executes entirely in your browser. The library file is served from this site, not a CDN, so the page works offline once loaded and makes zero external requests. Most splitter sites ask you to upload the whole document first; here your file never leaves your device.

    Common ways people use a PDF splitter

    Send only the pages that matter. A contract, a medical record or a tenancy agreement often contains pages the other side does not need. Extract the relevant pages into a fresh PDF and share that instead of the whole file.

    Pull one chapter out of a report. A long annual report or manual becomes usable once the chapter you actually need is its own short document — easier to attach, easier to read on a phone.

    Break a scan into single pages. A scanner that saves a whole stack as one PDF is no help when a form wants one page per upload. Burst mode gives you one file per page, named by page number.

    Remove blank or unwanted pages. Extract everything except the pages you do not want — for example 1-4, 6-12 to drop a blank page 5 — and the result is a clean document with no gaps.

    How to use

    1. Drop one PDF into the upload box (or click to browse). The tool shows how many pages it has.
    2. Choose Extract pages for one new PDF, or One file per page for a separate file per page.
    3. For extraction, type the pages: 1-3, 5, 8-, or use the All / Odd / Even shortcuts.
    4. Click Split PDF and download the result. Check the page count before sending it on.

    Worked example

    Take a 12-page PDF and extract pages 3–5. Enter the range 3-5, click Split PDF, and you get one new 3-page PDF containing only those pages. To get one file per page instead, choose the 'One file per page' option and you get 12 single-page files.

    Limitations

    • Files up to 50 MB. Very large scanned documents (hundreds of pages) can be slow and memory-hungry on low-end devices — split them on a desktop when you can.
    • Password-protected (encrypted) PDFs cannot be split — remove the password first in your PDF reader.
    • Interactive form fields do not survive — split PDFs are read-only; fill forms before splitting.
    • Digital signatures break: a signature is bound to the exact bytes of the original file, so always split first and sign the final document last.
    • Bookmarks and outlines from the original may not carry over into the split files.
    • Burst mode gives one download link per page — there is no ZIP download, so download the pages you need individually.
    • Pages are copied unchanged: splitting does not compress anything, so a big scanned page stays big.

    Frequently asked questions

    How do I split a PDF without uploading it?

    Drop the PDF into the tool above, pick the pages you want (for example 1-3, 5), and click Split PDF. The split runs entirely in your browser — your document is never uploaded to any server, unlike most online PDF splitters.

    What page ranges can I extract?

    Single pages (5), ranges (1-3), lists (1-3, 5, 8-), an open-ended range (8- means page 8 to the end), or the words all, odd and even. Pages are extracted in the order you list them, duplicates removed.

    Can I split a PDF into one file per page?

    Yes. Choose the 'One file per page' mode and each page is saved as its own single-page PDF, with one download link per page. There is no ZIP download — download the pages you need individually.

    Is there a file size limit?

    Files up to 50 MB are accepted. The practical limit is your device's memory: very large scanned documents with hundreds of pages can be slow on a phone, so split large files on a desktop when you can.

    Can I split a password-protected PDF?

    No — encrypted files are rejected. Open the PDF in a reader, remove the password, save an unprotected copy, and then split it.

    Does splitting change the pages?

    No. Pages are copied at the PDF object level, so text stays selectable, fonts and images keep their quality, and each page keeps its original size and rotation. Nothing is re-rendered or compressed.

    Do digital signatures survive splitting?

    No. A digital signature is bound to the exact contents of its file, so it becomes invalid the moment pages are extracted. Split first, then sign the finished document.

    Can I split a scanned PDF?

    Yes — splitting copies pages as they are, so a scanned PDF splits the same way; no text is extracted.
