    About this image resizer

    Oversized photos slow down websites, bounce off email attachment limits and eat phone storage. This free image resizer shrinks (or enlarges) any photo while preserving its aspect ratio, so nothing comes out stretched or squashed. Resize by exact pixel width or height, by longest side, or by percentage — handy for batch-feeling one-off jobs like forum avatars, marketplace listings and blog images.

    Resizing happens on an HTML canvas entirely on your device: the pixels are resampled locally with high-quality smoothing and the result is encoded to PNG, JPG or WebP right in the page. Because nothing is uploaded, there is no queue, no watermark and no account — and sensitive photos (IDs, screenshots, client work) never touch a server. That privacy edge is exactly where most online resizers fall short: they require an upload before they do anything.

    The aspect-ratio math, worked out

    The tool always preserves your image's proportions — it never stretches. Here is what that means in practice, with the exact results this page produces:

    • 4000×3000 photo → 800 px wide. The ratio is 4:3, so the height becomes 3000 × 800 ÷ 4000 = 800×600 px.
    • 4032×3024 iPhone photo → longest side 1024. The width is the longest side, so the result is 1024×768 px (3024 × 1024 ÷ 4032 = 768).
    • 1920×1080 video still → 50%. Percentage mode scales both sides equally: 960×540 px, still exactly 16:9.
    • 6000×4000 marketplace photo → height 1067. Setting the height gives 6000 × 1067 ÷ 4000 ≈ 1600.5, which rounds to 1600×1067 px — one pixel off the exact ratio, which is invisible in practice.

    That rounding is worth a sentence: pixels are indivisible, so any resize rounds each dimension to a whole pixel. On odd dimensions the ratio shifts by less than a pixel — nothing a human eye can detect.

    1. Drop an image into the upload box (or click to browse).
    2. Pick a resize mode — percentage, exact width, exact height, or longest side — and enter the value.
    3. Choose the output format (PNG for graphics, JPG for photos, WebP for the web).
    4. Click Resize image, then download the result with its new dimensions in the filename.

    Limitations

    • Enlarging beyond ~200% will look soft — resizing cannot invent detail that is not in the original.
    • Animated GIFs are resized as a single still frame; animation is not preserved.
    • The tool resizes proportionally only — it cannot crop, rotate or stretch an image into a different shape. For a square avatar from a landscape photo, crop elsewhere first.
    • Dimensions round to whole pixels, so results on odd sizes can differ from the exact ratio by a single pixel.
    • Very large images (50+ megapixels) may hit browser memory limits on low-end devices.
    • JPG output uses high quality (0.92); for aggressive file-size shrinking use the Image Compressor instead.

    Frequently asked questions

    How do I resize an image without losing quality?

    Shrinking an image preserves perceived quality well because you are discarding pixels, not inventing them. This tool resamples with the browser’s high-quality smoothing and keeps the exact aspect ratio, so the result looks clean. Enlarging is the opposite: quality always drops because new pixels must be guessed.

    What is the best image size for a website?

    It depends on placement: hero images are typically 1600–2000px wide, blog content images 800–1200px, and thumbnails 300–400px. Resize to the display size and serve WebP — most sites load far faster with no visible difference.

    Are my images uploaded to a server?

    No. The resize runs 100% in your browser using the HTML canvas API. Your images never leave your device, are never stored, and never sent anywhere.

    Which output format should I choose?

    JPG for photographs (smallest files), PNG for graphics with sharp edges or transparency, WebP for the best of both on modern browsers.

    How do I resize without stretching or distorting the image?

    You don't have to do anything — this tool always locks the aspect ratio, so the image can never come out stretched or squashed. Set one dimension (width, height, longest side or percentage) and the other is calculated automatically. If you need an exact square or a specific shape, crop the image to that shape first in any editor, then resize; resizing and cropping are different operations, and this page deliberately does only the first.

    What's the difference between resizing and compressing?

    Resizing changes the pixel dimensions (4000×3000 becomes 800×600); compressing reduces the file size at the same dimensions by lowering quality. They solve different problems: resize when the image is physically too big for its display slot, compress when the file is too heavy to send. For web publishing, do both — resize to the display size first, then run the result through the Image Compressor.

    Can I enlarge a small image for printing?

    Technically yes — percentage mode goes up to 1000% — but enlarging cannot add detail, so the result gets soft past roughly 200%. A practical rule: divide your pixel dimensions by the print resolution. An 800×600 image prints at 300 dpi to about 2.7 × 2 inches — fine for a small insert, not for a poster. For anything larger you need a bigger original, not a bigger resize.

    Why did my file get bigger after shrinking it?

    Usually a format mismatch: shrinking a photographic PNG and saving it as PNG again keeps the inefficient lossless encoding, so a 1.8 MB screenshot can still be large at smaller dimensions. If the file needs to be small, also switch the output format — JPG or WebP for photos — and consider the Image Compressor, which is purpose-built for file size. Resize controls dimensions; format and quality control file size.
