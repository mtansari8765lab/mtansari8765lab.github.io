About this character counter

Character limits decide whether your message fits: social media bios, post captions, SMS messages, form fields, and SEO meta descriptions all cut you off at a fixed number of characters. The trouble is that "characters" is not always counted the way you expect — some platforms count emoji as two characters, others limit by bytes instead. This free character counter shows every count that matters, live as you type: total characters, characters excluding spaces, words, lines, and the exact UTF-8 byte length.

Counting is Unicode-safe. Each emoji counts as one character (many naive counters report two because they count UTF-16 code units), and the UTF-8 byte readout tells you the true storage size — useful when a database column, API, or SMS gateway enforces a byte limit, since accented characters take two bytes and most emoji take four. Writers use the excluding-spaces figure for assignments that ignore whitespace; marketers use the byte count to keep meta descriptions and ad copy inside technical limits.

Like every QuickTools utility, the counter runs entirely on your device. Paste confidential drafts freely — nothing is uploaded or stored.

Worked example

Type Hello world! 😀 into the box and the counter reports: 14 characters, 12 characters excluding spaces, 3 words, 1 line, and 17 UTF-8 bytes. Notice the two numbers the emoji produces: it is one character (14, not 15), but four bytes (17 bytes for 14 characters). That gap is exactly what breaks naive counters and SMS gateways — this one shows you both figures so you are never guessing. Try a sentence of your own, such as SEO meta descriptions should stay under 160 characters for best display. — 72 characters, 62 excluding spaces, 11 words, 72 bytes.

Who uses a character counter

Social media managers check bios, captions and post text against each platform's ceiling before publishing. SEO specialists keep meta descriptions around 150–160 characters and page titles near 50–60 so search results show the full text instead of cutting it off with an ellipsis. SMS marketers stay within the 160-character segment: one segment is cheap, two segments double the cost, and a single emoji can force a message into costlier UCS-2 encoding — the byte readout warns you early. Students and freelancers verify minimum and maximum counts on essays and paid articles. Developers validate input against database column limits and API constraints, where bytes matter more than characters. Translators compare source and target lengths to spot text that will overflow a fixed-size button or banner.

Limitations

  • Some platforms (notably X/Twitter) count certain characters, URLs and emoji with their own weighted rules — this tool reports standard Unicode counts, not platform-specific ones.
  • Complex emoji sequences joined with zero-width joiners (e.g. family emoji) count by code point, which may differ from what a platform displays as one glyph.
  • Line breaks count as characters in the total; the excluding-spaces count removes all whitespace including line breaks.
  • The "ideal" meta description length (150–160 characters) is a display convention, not a rule — Google truncates by pixels, so wide letters like "W" eat more of your budget than the count suggests.

Frequently asked questions

Do spaces count as characters?

The main character count includes spaces and line breaks. A separate "excluding spaces" count is shown for platforms and assignments that ignore whitespace.

How are emoji counted?

Each emoji counts as one character. The counter measures Unicode code points, not UTF-16 code units, so emoji are never counted as two characters.

What is the UTF-8 byte count for?

Some systems — databases, APIs, SMS gateways, meta description validators — limit text by bytes rather than characters. Accented letters take 2 bytes and most emoji take 4, so byte count and character count can differ.

Is my text sent to a server?

No. Counting happens entirely in your browser. Your text never leaves your device.

How many characters should a meta description be?

Aim for roughly 150–160 characters so search results show the whole description instead of cutting it off. Paste your draft into the counter and trim until the total sits in that range — the excluding-spaces figure is irrelevant here; Google counts everything.

What is the SMS character limit?

A standard text message is 160 characters. Longer messages are split into multiple segments, each billed separately — and one emoji can switch the whole message to a costlier encoding that shrinks each segment to 70 characters. The UTF-8 byte readout helps you spot that before sending.

Do line breaks affect the count?

Yes. Each line break counts as one character in the total. The excluding-spaces count removes all whitespace, including line breaks and tabs, so it is the figure to use when whitespace does not count.

Does the counter count words too?

Yes. Alongside characters it shows word count and line count, live as you type. Use the Copy stats button to copy a one-line summary of all five figures to your clipboard.
